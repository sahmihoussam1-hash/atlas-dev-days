# Atlas Dev Days 2026 🚀

Site web vitrine pour la conférence **Atlas Dev Days 2026**, un événement dédié au développement web moderne (09 & 10 octobre 2026 à Casablanca).

---

## 📌 Structure du Projet

Le projet est développé en HTML5 sémantique et CSS3 pur.

---

## 💻 Pages du Site

- **Accueil (`acceuil.html`) :** Présentation globale de l'événement, lieu, dates et bouton d'action.
- **Programme (`programme.html`) :** Tableau détaillé des conférences sur 2 jours (Web Components, CSS Grid, Sécurité, A11y...).
- **Intervenants (`intervenant.html`) :** Cartes de présentation des différents speakers.
- **Inscription (`inscription.html`) :** Formulaire complet avec validation des champs (nom, e-mail, téléphone, choix du pass).

---

## 🚀 Utilisation

1. Clonez ou téléchargez le dépôt.
2. Ouvrez le fichier `acceuil.html` dans n'importe quel navigateur web.

---

## 🛠️ Technologies utilisées

- **HTML5** (Structure sémantique)
- **CSS3** (Flexbox, styles responsive)
